# Disclosure: use of software tools

Portions of the code and text in this repository, in particular the library modules (core/, charts/, sources/, scripts/), the example app, the README and the design document (DESIGN.md), were drafted with the aid of a large language model coding tool: Anthropic Claude Opus 5.5 (model ID `claude-opus-5-5`), accessed through the Claude Code command-line tool, beginning October 2026. Most of the library code was extracted from the tpl-cities and ca-30x30 Assessment Explorer apps, which were developed the same way.

The authors directed this work and reviewed, tested and validated the results, including checks that the library generates the same SQL as both source apps for every query and area, reproduces their precomputed results, and renders their reports identically. The authors take full responsibility for the code and text, and any errors they contain.
